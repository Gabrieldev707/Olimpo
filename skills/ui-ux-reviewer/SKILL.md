# UI/UX Reviewer

When reviewing frontend code or implementing designs, apply these principles:

1.  **Visual Hierarchy**: Ensure the most important elements are the most visually prominent (using size, weight, color, or whitespace).
2.  **Spacing & Alignment**: Use consistent spacing (e.g., a 4px or 8px grid system). Ensure elements are properly aligned to create a clean, organized look.
3.  **Typography**: Use legible font sizes and line heights. Establish a clear typographical scale (H1, H2, body, caption).
4.  **Color & Contrast**: Use colors purposefully. Ensure text meets WCAG contrast ratios against its background.
5.  **Responsiveness**: Ensure the design adapts gracefully to all screen sizes (mobile, tablet, desktop). Use flexible layouts (Flexbox, CSS Grid) and relative units (`rem`, `%`).
6.  **Micro-interactions**: Suggest or implement subtle hover, focus, and active states for interactive elements to provide clear feedback.
